# CSV AI Viewer: Application Documentation

## 1. Introduction

The CSV AI Viewer is a sophisticated, web-based application designed to revolutionize the way users interact with and analyze CSV data. It transforms static, cumbersome spreadsheets into a dynamic, interactive experience, rivaling the capabilities of modern business intelligence tools like Microsoft Excel and PowerBI. The application provides a feature-rich data table, an interactive dashboard for data visualization, and, most notably, an integrated AI assistant powered by Google Gemini for advanced data analysis through natural language queries.

This tool is built for a wide range of users, from data analysts and business professionals to students and researchers. Whether you need to quickly clean and analyze a dataset, create compelling visualizations for a presentation, or uncover deep insights hidden within your data, the CSV AI Viewer provides a powerful, intuitive, and all-in-one solution. Its primary goal is to democratize data analysis, making it accessible to users of all technical skill levels, and to accelerate the journey from raw data to actionable intelligence.

## 2. Technologies Used

The CSV AI Viewer is built on a modern, robust technology stack, ensuring a seamless and responsive user experience. The application is divided into a powerful backend for data processing and a dynamic frontend for user interaction.

### 2.1. Backend Technologies

*   **Python**: The core language for the backend logic.
*   **Flask**: A lightweight and flexible web framework for Python, used to build the server and API endpoints.
*   **Pandas**: A fundamental library for data manipulation and analysis, used for all CSV data handling.
*   **NumPy**: A powerful library for numerical operations, used in conjunction with Pandas for efficient data processing.
*   **Google Gemini**: A state-of-the-art generative AI model from Google, which powers the natural language query and analysis features.
*   **XlsxWriter, xlrd, openpyxl**: Libraries used for exporting data to Microsoft Excel format with rich features like multiple sheets and statistics.
*   **Flask-CORS**: A Flask extension for handling Cross-Origin Resource Sharing (CORS), allowing the frontend to communicate with the backend API.

### 2.2. Frontend Technologies

*   **HTML5**: The standard markup language for creating the structure of the web application.
*   **CSS3**: Used for styling the application, creating a modern, responsive, and user-friendly interface, including features like dark mode.
*   **JavaScript (Vanilla)**: The primary language for client-side logic, handling all user interactions, data rendering, and communication with the backend. The application is built without a major frontend framework to ensure maximum compatibility and performance.
*   **Font Awesome**: A popular icon library used to provide intuitive icons throughout the application, enhancing user experience.

## 3. Core Functionalities

The CSV AI Viewer is designed around three primary functionalities that provide a comprehensive data analysis workflow, from data import to insight generation.

### 3.1. Data Import and Handling

The application starts with a seamless data import process. Users can upload CSV files either by browsing their local files or by using a simple drag-and-drop interface. The backend is equipped with a robust CSV parser built on top of the Pandas library, which can handle various CSV formats and encodings. Upon upload, the application intelligently detects data types, distinguishing between numerical, categorical, and date-based columns, and displays key file information such as the number of rows and columns.

### 3.2. Interactive Data Table

Once the data is loaded, it is presented in an Excel-like data table that is both powerful and intuitive. This is the central hub for data exploration and manipulation. Users can perform a wide range of actions, including:

*   **Sorting and Filtering**: Sort data by any column in ascending or descending order, and apply global or column-specific filters to drill down into the data.
*   **Inline Editing**: Directly edit cell values within the table, allowing for quick corrections and data cleaning.
*   **Pagination**: Efficiently navigate through large datasets with customizable pagination controls.
*   **Column Management**: Hide, rename, and reorder columns to customize the data view.

### 3.3. PowerBI-Style Dashboard

For users who want to visualize their data, the application offers a PowerBI-style dashboard. This feature allows users to create a variety of interactive charts and graphs to uncover trends and patterns. Key dashboard functionalities include:

*   **Chart Creation**: Generate multiple chart types, including bar, line, pie, scatter, area, and histograms, by selecting the desired data for the X and Y axes.
*   **Interactive Controls**: Customize charts with options for aggregation (sum, average, count), color coding, and time-based grouping.
*   **Advanced Analytics**: The dashboard displays key performance indicators (KPIs), statistical summaries, and data quality metrics in real-time.

### 3.4. AI-Powered Analysis with Gemini

The standout functionality of the CSV AI Viewer is its AI assistant, powered by Google Gemini. Through a natural language chat interface, users can ask complex questions about their data and receive intelligent answers, code, and visualizations. This feature democratizes data analysis by allowing users to:

*   **Query Data in Plain English**: Ask questions like "What are the top 5 selling products?" or "Show me the average revenue by region."
*   **Generate Code**: The AI assistant can generate Python (Pandas) or JavaScript code to perform the requested analysis, which is then executed to provide the answer.
*   **Receive Insights and Recommendations**: The AI can provide automated insights, identify trends, and suggest further analysis, acting as a personal data analyst.

## 4. Key Features

The CSV AI Viewer is packed with a wide array of features designed to provide a comprehensive and user-friendly data analysis experience.

### 4.1. Data Table Features

*   **Excel-like Interface**: An intuitive and familiar interface for users accustomed to spreadsheet software.
*   **Advanced Sorting and Filtering**: Multi-column sorting, global text search, and column-specific filters with multiple selection.
*   **Inline Editing**: Click any cell to edit its content directly. Changes are saved instantly.
*   **Pagination**: Customizable rows per page (25, 50, 100, 200) to handle large datasets gracefully.
*   **Column Controls**:
    *   **Hide/Show Columns**: Temporarily hide columns to focus on relevant data.
    *   **Rename Columns**: Easily rename columns to be more descriptive.
    *   **Reorder Columns**: Drag and drop column headers to reorder them.
*   **Data Export**:
    *   **Export to CSV**: Download the current view of the data as a CSV file.
    *   **Export to Excel**: Export to an `.xlsx` file, which includes a separate sheet with detailed statistical analysis of the data.
*   **Data Manipulation**:
    *   **Add/Delete Rows**: Easily add new rows or delete existing ones.
    *   **Add/Delete Columns**: Add new columns with a specified name.
*   **Data Validation**: Automatic detection of data types (numeric, categorical, date) and validation rules.
*   **Undo/Redo**: Undo and redo actions to prevent accidental data loss.
*   **Find and Replace**: A powerful tool to find and replace text across the entire dataset, with options for case sensitivity and whole-word matching.
*   **Conditional Formatting**: Apply custom formatting rules to cells based on their values (e.g., color-coding high or low values).

### 4.2. Dashboard Features

*   **PowerBI-style Dashboard**: A dedicated view for creating and interacting with data visualizations.
*   **Multiple Chart Types**:
    *   Bar Chart
    *   Line Chart
    *   Pie Chart
    *   Scatter Plot
    *   Area Chart
    *   Histogram
    *   Heatmap
    *   Box Plot
    *   Funnel Chart
    *   Radar Chart
*   **Interactive Chart Controls**:
    *   Select X and Y axes from any column.
    *   Group data by time (Year, Quarter, Month, Week, Day).
    *   Apply aggregation functions (Sum, Average, Count, Min, Max, Median).
    *   Color-code charts by a third data column.
*   **Advanced Analytics**:
    *   **Statistical Summary**: View a summary of key statistics for numeric columns.
    *   **Outlier Detection**: Automatically identify and highlight potential outliers in the data.
    *   **Correlation Matrix**: View a matrix of correlation coefficients between numeric columns.
*   **Real-time Metrics**:
    *   Key Performance Indicator (KPI) cards for a quick overview of the data (e.g., total records, missing values, data quality score).
*   **Calculated Fields**: Create new data fields based on custom formulas and calculations.
*   **Drill-Down Capabilities**: Interactively drill down into chart data to explore it at a more granular level.

### 4.3. AI Integration Features

*   **Natural Language Queries**: Interact with the AI assistant using plain English, eliminating the need for complex query languages.
*   **Intelligent Analysis**: The AI can perform a wide range of analyses, from simple data summaries to complex statistical tests.
*   **AI-Assisted Data Cleaning**: Use the AI to suggest and perform data cleaning operations, such as handling missing values or correcting data types.
*   **AI-Assisted Data Filtering**: The AI can generate complex filters based on natural language descriptions (e.g., "show me all sales from last quarter in the west region").
*   **Code Generation**: For transparency and educational purposes, the AI can show the Python (Pandas) or JavaScript code it generated to answer a query.
*   **Context-Aware Suggestions**: The AI provides context-aware suggestions for further analysis based on the current state of the data.

### 4.4. User Experience Features

*   **Dark Mode**: Switch between light and dark themes for comfortable viewing in any environment.
*   **Keyboard Shortcuts**: A comprehensive set of keyboard shortcuts for power users.
*   **Help and Documentation**: In-app help modals and detailed documentation.
*   **Responsive Design**: The application is designed to work seamlessly on various screen sizes.
*   **Health Check**: An API endpoint to verify that the backend server is running correctly.

By making data more accessible and easier to understand, the CSV AI Viewer can help businesses uncover new opportunities and foster innovation. This can lead to the development of new products, services, and business models, driving long-term growth and success.
